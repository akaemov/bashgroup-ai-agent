# Облицовка колонн гостиницы Lia by Minyoun

- **Раздел:** Рестораны и гостиницы
- **Страница:** https://bashgroup.ru/projects/restorany-i-gostinitsy/oblitsovka-kolonn-gostinitsy-lia-by-minyoun/

## Характеристики проекта

| Характеристика | Значение |
| --- | --- |
| Страна | Узбекистан |
| Местоположение | город Самарканд |
| Год сдачи | 2022 |
| Дизайнер | Metex (Turkey) |
| Проектировщик | ARUP (England) |
| Зоны отделки | фасады, колонны |

## Описание

Для данного объекта были использованы облицовки колонн диаметром 1500 миллиметров.

Особенностью стало то, что согласно дизайн-проекту, нанесена дизайнерская принтерная покраска сверху. И эта текстура дублируется с той, которая изображена на фасаде здания.
