# Реечные потолки для офиса СУ-1

- **Раздел:** Бизнес центры и офисы
- **Страница:** https://bashgroup.ru/projects/biznes-tsentry-i-ofisy/reechnye-potolki-dlya-ofisa-su-1/

## Характеристики проекта

| Характеристика | Значение |
| --- | --- |
| Страна | Россия |
| Местоположение | город Уфа |
| Год сдачи | 2019 |
| Дизайнер | SV Design (Уфа) |
| Зоны отделки | фойе, коридоры, офисные помещения |

## Описание

Спроектировали, изготовили и установили кубообразные потолки для офиса СУ-1

В проекте использовались реечные потолки CubForm Haken
