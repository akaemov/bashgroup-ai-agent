# Корзины для кондиционеров и потолки для ЖК Нугуманов

- **Раздел:** Жилые комплексы
- **Страница:** https://bashgroup.ru/projects/zhilye-kompleksy/korziny-dlya-konditsionerov-i-potolki-dlya-zhk-nugumanov/

## Характеристики проекта

| Характеристика | Значение |
| --- | --- |
| Страна | Россия |
| Местоположение | город Стерлитамак |
| Год сдачи | 2025 |
| Зоны отделки | фойе, коридоры, корзины для кондиционеров, фасады |

## Описание

Спроектировали и изготовили потолочные системы и корзины для кондиционеров

В проекте использовались:

- реечные кубообразные потолки CubForm Haken+
- потолочные кассеты HookForm Ansh+
- корзины для кондиционеров
