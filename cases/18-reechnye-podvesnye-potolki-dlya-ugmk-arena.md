# Реечные подвесные потолки для УГМК АРЕНА

- **Раздел:** Спортивные центры
- **Страница:** https://bashgroup.ru/projects/sportivnye-tsentry/reechnye-podvesnye-potolki-dlya-ugmk-arena/

## Характеристики проекта

| Характеристика | Значение |
| --- | --- |
| Страна | Россия |
| Местоположение | город Екатеринбург |
| Год сдачи | 2024 |
| Проектировщик | Проектный институт Екатеринбурггорпроект |
| Зоны отделки | фойе, коридоры и зоны перемещения, общественные пространства |

## Описание

Спроектировали, изготовили и произвели монтаж подвесных потолков для УГМК АРЕНА в Екатеринбурге.

В проекте использовались реечные подвесные потолки CubForm Haken и Anchor
