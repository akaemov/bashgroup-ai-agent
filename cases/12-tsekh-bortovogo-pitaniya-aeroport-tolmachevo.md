# Цех бортового питания Аэропорт Толмачево

- **Раздел:** Аэропорты и вокзалы
- **Страница:** https://bashgroup.ru/projects/aeroporty-i-vokzaly/tsekh-bortovogo-pitaniya-aeroport-tolmachevo/

## Характеристики проекта

| Характеристика | Значение |
| --- | --- |
| Страна | Россия |
| Местоположение | город Новосибирск |
| Год сдачи | 2019 |
| Зоны отделки | кухонный цех, чистое помещение |

## Описание

В проекте использовались потолочные панели для чистых помещений ClipForm Poly.

Спроектировали, изготовили и установили потолки в чистом помещении цеха питания Аэропорта.
