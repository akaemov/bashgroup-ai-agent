# Реечные потолки для ЖК Лайт в Уфе

- **Раздел:** Жилые комплексы
- **Страница:** https://bashgroup.ru/projects/zhilye-kompleksy/reechnye-potolki-dlya-zhk-layt-v-ufe/

## Характеристики проекта

| Характеристика | Значение |
| --- | --- |
| Страна | Россия |
| Местоположение | город Уфа |
| Год сдачи | 2022 |
| Зоны отделки | фойе, коридоры и зоны перемещения, ресепшн, лифтовые холлы |

## Описание

В проекте использовались реечные потолки CubForm Haken.

Для основных проходных зон, вестибюля и поэтажных холлов реализован кубообразный реечный подвесной потолок. Все выполнено строго по дизайн-проекту.

Заказчик остался доволен полученным результатом.
