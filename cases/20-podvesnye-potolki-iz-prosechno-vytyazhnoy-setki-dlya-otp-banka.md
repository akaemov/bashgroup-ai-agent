# Подвесные потолки из просечно вытяжной сетки для ОТП Банка

- **Раздел:** Банки
- **Страница:** https://bashgroup.ru/projects/banki/podvesnye-potolki-iz-prosechno-vytyazhnoy-setki-dlya-otp-banka/

## Характеристики проекта

| Характеристика | Значение |
| --- | --- |
| Страна | Россия |
| Местоположение | город Москва |
| Год сдачи | 2018 |

## Описание

Спроектировали, изготовили и установили подвесные потолки из просечно вытяжной сетки для ОТП банка

В проекте использовались потолки BandForm Triang
