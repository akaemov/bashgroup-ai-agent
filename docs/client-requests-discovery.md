## Исходные сведения и границы

- По словам пользователя, менеджеры не успевают обрабатывать заявки достаточно быстро.
- Два направления для исследования: увеличение пропускной способности менеджеров и фильтрация/приоритизация заявок. Направление пока не выбрано; выбор предстоит обсудить с Азатом. Взаимоисключаемость направлений не установлена.
- Начинаем с увеличения пропускной способности, конкретно с подготовки коммерческих предложений. Затем разбираем приоритизацию.
- По текущим сведениям участников, больше всего времени занимает формирование КП. Это исходное наблюдение без замеров и без подтверждения, что оно единственное узкое место.
- Денежные пороги (100 тысяч, миллион) и доступность выполнения сейчас приведены пользователем как примеры, не как коммерческие правила.
- Бриф конкурентной разведки оставлен без дальнейшего разбора; новый сценарий ведётся отдельно.
