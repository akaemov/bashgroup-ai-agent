# БАШГРУПП — кабинет AI-агентов

Веб-кабинет для Азата, собственника и коммерческого директора БАШГРУПП: исследования, конкуренты, рынок, потенциальные заказчики, закупки и подготовка коммерческих предложений.

**Начать с [полного контекста проекта](PROJECT_CONTEXT.md).** В нём история работ, договорённости, текущий статус, ограничения и план продолжения.

Демонстрация: **http://81.222.148.50**. Визуальное направление одобрено, основной формат — компьютер.

## Текущее состояние

| Часть | Статус |
|---|---|
| UI пяти агентов | Кликабельный прототип v0.2, демонстрационные данные |
| PostgreSQL 16 | Установлен на VPS, миграция `0001_initial` применена |
| Начальные данные | 5 агентов, 1 скилл, 5 кандидатов, каталог и 20 кейсов |
| Резервные копии БД | Ежедневный timer, проверено восстановление |
| Связь UI с БД | Пока отсутствует; решения прототипа в localStorage |
| Backend API и авторизация | Следующий этап |
| YandexGPT и реальное выполнение агентов | Ещё не подключены |

## Запустить UI локально

В каталоге `ui`:

```sh
npm ci
npm run dev
```

Проверка типов и сборка: `npm run build`. Для просмотра демоверсии локальная БД не нужна.

## PostgreSQL

Схема и скрипты — в `backend/`. Инструкция восстановления с нуля — в [backend/README.md](backend/README.md). Команда `provision.py` рассчитана на чистый Ubuntu VPS, выполняется один раз и требует root; не запускайте её поверх существующей базы без изучения инструкции.

Пароли и серверный `database.json` не входят в репозиторий. Файлы `dist`, `node_modules`, `.venv` и дампы также не публикуются.

**Ближайший рабочий этап:** API и авторизация → серверное хранение задач/отчётов/решений → подключение YandexGPT → первый реальный запуск конкурентной разведки.
