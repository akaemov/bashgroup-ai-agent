# Кабинет агентов БАШГРУПП — прототип

React + TypeScript + Vite. Демонстрационный интерфейс без API и секретов.

**Актуальный фокус разработки — агент подготовки КП**, первый рабочий агент системы. Обновлённая очередь и вопросы: [PROPOSALS_AGENT.md](../docs/PROPOSALS_AGENT.md). UI пока остаётся прототипом пяти направлений; смена приоритета не означает подключение рабочего расчёта или генерации документов.

## Запуск

```sh
npm ci
npm run dev
# Проверка типов и production-сборка
npm run build
```

## Размещение

Исходники и сборка на VPS: `/opt/agents/bashgroup-ai-agent/ui`.
Nginx отдаёт `dist` на `http://81.222.148.50`. Пример конфигурации: `deploy/nginx.conf`.
Для обновления собрать проект и перенести `dist`, сохранив соответствующие исходники.
Node.js нужен только для сборки; веб-сервер работает независимо от SSH-сессии.

## Возможности и границы

- Обзор, карточки агентов, профили конкурентов, сравнение, отчёты и согласования.
- Сценарий передачи проекта из разведки агенту подготовки КП.
- Решения и комментарии сохраняются в localStorage данного браузера. Сброс — в диалоге «Как устроен кабинет».
- Добавленные кандидаты и состояние демонстрационной задачи существуют до перезагрузки страницы.
- Запуск исследования имитируется таймерами, отчёт заранее подготовлен. Никаких реальных рыночных выводов нет.
- Внешние уведомления, модель, поиск, аутентификация, расписания, скачивание и отправка КП не подключены. PostgreSQL уже установлен отдельно, но UI ещё не обращается к нему: backend API пока отсутствует.
- Публичный прототип не должен содержать конфиденциальные документы и реальные контакты клиентов.

- Поиск заказчиков: 4 синтетических проекта с потребностями, объёмами, стадиями и пробелами; поиск, сегменты и вкладка переданных в работу проектов.
- Анализ закупок: 3 синтетические закупки, тип процедуры, сроки, суммы, технические проверки и риски; поиск и фильтрация.

- Данные вымышлены; никакие организации, проекты и закупки в демонаборе не заявляются реальными. Числа не являются результатами анализа рынка.

## Зафиксированные продуктовые требования

1. Азат — собственник, коммерческий директор, руководитель продаж и производства. Главный фокус — коммерческий.
2. Главный сценарий — исследования всех агентов, новые сведения, отчёты и конкуренты.
3. Пользователи: Азат и разработчик. Позднее — сотрудники с разграничением прав по агентам и действиям. Реальная авторизация вне прототипа.
4. Агенты: конкурентная разведка, КП, рынок, заказчики, закупки. Единая расширяемая структура.
5. Азат — главный оркестратор. Агенты работают по сценариям; пример: проект → КП → согласование → отправка. Обратная связь используется для уточнения инструкций, а не обещания автоматического дообучения.
6. Приоритет: дашборды и отчёты → кнопки и формы → чат.
7. В разведке: профили → решения по рекомендациям → сравнения → остальные возможности.
8. Краткая управленческая сводка с раскрытием деталей. Скачивание файлов — в будущем.
9. Азат управляет бизнес-данными (конкуренты, темы, источники), разработчик — скиллами, кодом, API и сценариями.
10. Ручной запуск и расписание. Кто меняет расписание — уточнить.
11. Внешние уведомления только о существенном изменении/перспективном проекте и необходимости согласования. Канал пока не выбран.
12. Desktop-first. Полноценная мобильная версия позднее.
13. Светлый интерфейс, синий акцент, графитовое меню по мотивам bashgroup.ru. Пока без логотипа.
14. Первая версия — кликабельный прототип с явно обозначенными демоданными.
