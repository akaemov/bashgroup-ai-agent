## Что установлено

- PostgreSQL 16.15, Ubuntu-пакеты `postgresql-16`, `postgresql-client-16`.
- Кластер `16/main`, системный сервис с автозапуском.
- База `bashgroup`, схема `app`; часовая зона БД UTC.
- Подключение по TCP только `127.0.0.1:5432` (проверено через `ss`); Unix socket доступен локально.
- Парольная аутентификация TCP — `scram-sha-256`; локальный административный доступ — `peer`.
- `.venv` на VPS с SQLAlchemy, psycopg и Alembic; проверка `pip check` прошла.
- Миграция `0001_initial` — head, 14 предметных таблиц + `app.alembic_version`.
- Вторая команда `upgrade head` не создаёт повторную схему; повтор seed не дублирует начальные записи.

## Разделение доступа

- `bashgroup_owner` — владелец схемы и таблиц, NOLOGIN.
- `bashgroup_migrator` — отдельный пароль, NOINHERIT, миграции явно переключают роль на owner.
- `bashgroup_app` — CRUD, без DDL, superuser и управления ролями. `alembic_version` доступна только на чтение.
- Реквизиты: `/etc/bashgroup/database.json`, права `0600`, каталог `0700`, root:root. Пароли не включены в исходники и этот документ.

2. Запрет CREATE TABLE/SCHEMA, ALTER TABLE, TRUNCATE, SET ROLE owner и записи в alembic_version.
