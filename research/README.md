# Research

`research/` хранит рабочие материалы по исследованию и развитию проекта: конспекты встреч, брифы, ответы на вопросы, исследовательские заметки и TODO.

## Индекс тем

- [`competitive-intelligence-agent/`](competitive-intelligence-agent/README.md) — агент конкурентной разведки; текущая активная тема. Здесь собраны брифы, журнал discovery и конспекты встреч по направлению.
- [`commercial-proposal-preparation/`](commercial-proposal-preparation/README.md) — подготовка коммерческих предложений; ответы Азата, требования к пилоту и открытые действия.

## Как поддерживать индекс

При появлении новой самостоятельной темы создаём `research/<тема>/README.md`, добавляем её в список выше и фиксируем в тематическом README путь, тип, дату и статус каждого материала. Подробные правила — в корневом [`AGENTS.md`](../AGENTS.md).
