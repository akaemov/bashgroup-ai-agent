# Разработать схему хранения данных о возможностях БАШГРУПП

## Зачем

Спроектировать источник истины для продукции, материалов, услуг, производственных возможностей, текущей загрузки, коммерческих ограничений и кейсов. Агент должен получать из него проверяемый срез для ответа о возможности предложить решение потенциальному заказчику.

## Нужно определить

- сущности, связи и статусы данных;
- обязательные поля, владельцев и даты актуальности;
- историю изменений и правила архивации;
- процесс ручного обновления и проверки;
- интерфейс для команды;
- интеграции с существующими источниками;
- технологию хранения и API/адаптер для агентного слоя.

## Не входит сейчас

Выбор конкретной СУБД, реализация схемы, миграции и интеграции.
