# Реестр источников для агента разведки объектов

**Назначение:** единый расширяемый список источников, из которых агент может получать сигналы о проектах, участниках и стадиях работ.

Это рабочий реестр, а не жёстко заданный набор ссылок. Его можно пополнять вручную; агент может предлагать новые источники, но не переводит их в активные без проверки человека.

## Правила работы

- Агент ищет только по источникам со статусом `активен`.
- Найденный новый ресурс агент добавляет или предлагает добавить со статусом `кандидат`, объясняя, какие сигналы он даёт и почему заслуживает проверки.
- Человек может добавить, отключить или удалить источник в любой момент.
- Для каждого источника фиксируются ссылка, тип, география, что именно он даёт, правила доступа, дата последней проверки и статус.
- Источник, который стал недоступен, потерял актуальность или даёт шум, переводится в `приостановлен` либо `архив`.
- Использование платного, закрытого или требующего учётной записи ресурса определяется отдельно; наличие ссылки не является разрешением обходить доступ.

## Статусы

- `активен` — агент может использовать при поиске.
- `кандидат` — найден человеком или агентом, ждёт оценки.
- `приостановлен` — временно не использовать.
- `архив` — сохранён для истории, не использовать.

## Карточка источника

Для каждого источника ведём:

- название;
- URL;
- тип: портал проектов, сайт застройщика, сайт архитектора, тендерная площадка, соцсеть, профильное медиа, реестр, партнёрский канал и т.д.;
- география;
- какие сигналы искать;
- какие сегменты/продукты покрывает;
- уровень доверия;
- статус;
- дата последней проверки;
- примечание: ограничения, способ поиска, ответственный.

## Стартовый пул

Пока конкретные URL не утверждены. Первым наполнением реестра станут проверенные источники по текущим рабочим объектам: сайты застройщиков, архитектурных бюро и генподрядчиков, профильные медиа и открытые проектные/тендерные площадки в согласованной географии.

Новые источники добавляем по мере работы, но сначала фиксируем их как `кандидат`.
